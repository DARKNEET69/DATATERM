Вход через GitHub

Введите Personal Access Token для доступа к репозиторию. Токен хранится только в sessionStorage до закрытия вкладки.

Как получить токен:
1. Перейди на github.com/settings/tokens
2. Нажми "Generate new token (classic)"
3. Выбери scope repo
4. Скопируй токен и вставь выше
